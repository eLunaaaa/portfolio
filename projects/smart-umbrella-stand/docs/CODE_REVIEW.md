# 코드 분석 및 검증 기록

검토일: 2026-10-14. 대상: 이 저장소의 C 모듈 및 Python 수집·학습 도구.

## 확인하고 수정한 오류

- 센서 디코더: 범위 밖 ADC 값이나 우산 플래그를 거부하고, 실패 시 기존 센서값을 보존하도록 수정했다. 기존 코드는 검증 실패 전에 출력값을 변경했다.
- Slave2 SPI: 네 바이트가 끝난 뒤 추가 바이트가 들어오면 이전 명령을 재적용하던 동작을 차단했다. 다음 NSS 선택까지 추가 바이트를 무시한다.
- Python 학습 입력: NaN/무한대, 잘못된 이진 라벨·우산 플래그, 습도 범위 오류, 런타임과 불일치하는 DH를 제외한다. DH는 H-HMEAN과 0.05 이내로 일치해야 한다.
- 학습 파라미터: 0 이하 또는 유효하지 않은 학습률과 0 이하 epoch를 거부한다.
- 테스트 실행 파일을 Git 제외 목록에 추가했다.

## 실행한 검증

- `make -C tests clean test`: C11, Wall/Wextra/Werror/pedantic 컴파일 및 프로토콜·날짜·제어·SPI 상태 머신 테스트 통과.
- 같은 테스트를 AddressSanitizer/UndefinedBehaviorSanitizer로 실행: 오류 없이 통과.
- Python: 유효/무효 CSV 혼합 입력 검증, 합성 dry/wet 두 샘플 학습, C 헤더 생성, 잘못된 학습률/epoch 거부 확인. 합성 샘플 결과는 실제 모델 성능 평가가 아니다.
- UART 수집 도구의 CLI 실행 확인. 실제 UART 데이터 수집은 미실시.

## 남아 있는 제약과 점검 항목

- STM32CubeMX 생성 파일, HAL, linker script, main.c, .ioc가 없어 보드 전체 컴파일·플래시를 검증하지 못했다.
- ESP8266 API 요청·응답 파싱과 LCD 코드는 공개본에 없다. README의 해당 기능은 팀 시제품 설명이다.
- 모델 가중치는 예시이며 실제 데이터셋과 평가 결과가 없다. 학습 도구의 실행 가능성과 모델의 현장 정확도는 별도다.
- SPI 타임아웃 후 DR/OVR 정리와 다음 프레임 복구, Slave1 NSS 조기 해제 시 재동기화는 실보드에서 검증해야 한다.
- Slave2 NSS 하강 인터럽트에서 헤더를 적재하므로 첫 SCK 전 충분한 시간을 확보해야 한다. 현재 Master 코드에는 명시적인 대기 보장이 없다. 실제 SPI 속도/IRQ 지연 검증이 필요하다.
- 날짜 함수는 1970년 미만을 거부하지만 여러 시간 차감 중 실패하면 이미 처리한 시간이 남을 수 있다. 현재 GMT→KST의 +9시간 용도에는 해당하지 않는다.
- 센서 보정, PWM 핀/타이머, 통신 실패 시 액추에이터 정지 정책과 watchdog은 보드 통합 단계에서 확인해야 한다.

따라서 현재 판정은 “호스트에서 검증한 핵심 로직 테스트 통과”이며 “시스템 전체에 오류 없음”을 보장하지 않는다.
