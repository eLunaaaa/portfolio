# 코드 분석 및 검증 기록

검토일: 2026-10-14. 대상: 이 저장소의 C 모듈 및 Python 수집·학습 도구.

## 확인하고 수정한 오류

- 센서 디코더: 범위 밖 ADC 값이나 우산 플래그를 거부하고, 실패 시 기존 센서값을 보존하도록 수정했다. 기존 코드는 검증 실패 전에 출력값을 변경했다.
- Slave2 SPI: 네 바이트가 끝난 뒤 추가 바이트가 들어오면 이전 명령을 재적용하던 동작을 차단했다. 다음 NSS 선택까지 추가 바이트를 무시한다.
- Python 학습 입력: NaN/무한대, 잘못된 이진 라벨·우산 플래그, 습도 범위 오류, 런타임과 불일치하는 DH를 제외한다. DH는 H-HMEAN과 0.05 이내로 일치해야 한다.
- 학습 파라미터: 0 이하 또는 유효하지 않은 학습률과 0 이하 epoch를 거부한다.
- 테스트 실행 파일을 Git 제외 목록에 추가했다.

## 실행한 검증

- `make -C tests clean test`: C11, Wall/Wextra/Werror/pedantic 컴파일 및 프로토콜·날짜·제어·SPI 상태 머신 테스트 통과.
- 같은 테스트를 AddressSanitizer/UndefinedBehaviorSanitizer로 실행: 오류 없이 통과.
- Python: 유효/무효 CSV 혼합 입력 검증, 합성 dry/wet 두 샘플 학습, C 헤더 생성, 잘못된 학습률/epoch 거부 확인.
- UART 수집 도구의 CLI 실행 확인.
