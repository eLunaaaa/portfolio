# 코드 검토와 검증

## 수정 사항

- 모델과 RTL의 입력 크기를 15×15로 통일하고 JSON을 공동 검증합니다.
- ReLU·Pool을 통과한 채널 수를 유지하고 FC의 채널 우선 flatten을 명시했습니다.
- top의 가중치·bias를 입력 포트로 연결했습니다.
- Conv·FC의 Q3.4 곱셈 소수점 정렬과 누적 폭, signed 포화를 정리했습니다.
- Pool의 조합·순차 루프 변수를 분리했습니다.
- 외부 도구의 출력 스트림을 합치고 명령 인자를 목록으로 전달합니다.
- sv2v에서 전체 모듈을 함께 변환하고 Yosys 최종 셀 통계를 추출합니다.
- 테스트 실패를 종료 코드에 반영하고 clean에서 학습 가중치를 보존합니다.

## 검증

설정 3종의 모델 구성과 순전파·역전파, 저장된 가중치 2종 로딩, Q3.4 평가 모드, 연산별 RTL 시뮬레이션과 baseline top 연결을 검사합니다. 재현 명령은 `make test`입니다.

추가로 작은 CNN 구성으로 sv2v 변환→Yosys 합성→최종 통계 JSON 저장→점수 계산 흐름을 실행했습니다. baseline과 두 합성곱 설정의 top RTL 컴파일도 통과했습니다.
