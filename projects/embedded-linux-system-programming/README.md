# Embedded Linux System Programming

졸업연구에서 담당한 C 기반 Linux 시스템 프로그래밍 작업을 정리했습니다. POSIX API 활용, 시간 처리, 메모리 관리와 실행 구간의 오버헤드 제어를 중심으로 구현했습니다.

## 사용 기술

| 영역 | 활용 기술 |
|---|---|
| 언어·환경 | C, Embedded Linux, POSIX API |
| 통신 API | Linux UDP socket |
| 시간 처리 | clock_gettime, clock_nanosleep, CLOCK_MONOTONIC, CLOCK_REALTIME |
| 메모리 관리 | mmap, mlockall, 사전 메모리 접근 |
| 데이터 처리 | 고정 폭 정수, byte order 변환, memcpy |
| 종료 처리 | sigaction, EINTR, 파일·메모리·소켓 자원 정리 |
| 구성·빌드 | 공통 헤더, Makefile, 컴파일 경고, eBPF/XDP 환경 설정 |

## 개인 기여

- C 기반 사용자 공간 모듈과 실행 옵션 처리 구현
- 시간 API를 이용한 반복 실행 기준과 시각 기록 처리
- 메모리 사전 준비와 반복 구간의 I/O·할당 부담 관리
- 데이터 형식·공통 설정·빌드 구성 정리
- 오류·종료 처리와 기능별 코드 설명 작성

## 기술적 구현 방식

### 초기화와 반복 처리 분리

소켓 생성, 설정 검사와 메모리 준비를 초기화 단계에서 수행했습니다. 반복 실행 구간에서는 필요한 API 호출과 데이터 기록에 집중하고, 개별 처리마다 발생하는 출력·파일 I/O를 줄였습니다.

### 시간 기준 구분

반복 실행 기준에는 CLOCK_MONOTONIC을, 시각 기록에는 CLOCK_REALTIME을 사용했습니다. 상대 지연을 계속 더하는 방식 대신 절대 시각 기준의 대기를 적용하고, EINTR 발생 시 같은 목표 시각을 기준으로 재시도하도록 처리했습니다.

### 메모리 준비와 데이터 기록

mmap으로 연속된 메모리 공간을 준비하고, mlockall과 사전 메모리 접근을 적용했습니다. 반복 구간에서 기록할 데이터를 준비된 공간에 저장하고, 실제 기록된 길이를 기준으로 종료 시 파일에 반영하도록 구성했습니다.

### 자료형과 바이트 순서 관리

고정 폭 정수와 byte order 변환을 사용해 데이터 표현을 명확히 했습니다. 수신한 바이트는 memcpy로 구조체에 옮겨 정렬을 고려한 접근을 수행하고, 입력 크기와 실행 옵션을 검사했습니다.

### 신호 처리와 자원 정리

신호 처리기에서는 종료 플래그만 변경했습니다. 메인 실행 흐름에서 중단 조건을 확인한 뒤 파일 저장, 메모리 해제와 소켓 종료를 수행하도록 구성했습니다.

### 설정과 빌드 일관성

여러 모듈에서 사용하는 설정을 공통 헤더로 모았습니다. eBPF/XDP 환경의 설정 참조와 Makefile을 정리하고, 컴파일 시 상수 관계를 확인하는 검사와 경고 옵션을 적용했습니다.
