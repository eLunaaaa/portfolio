# Demo assets

prototype.png, general-demo.png, can-demo.png, glass-demo.png, pet-demo.png, dashboard-report.png, vivado-block.png는 사용자 제공 프로젝트 보고서의 시제품 사진과 화면에서 추출한 자료다.

원 보고서의 개인 평가·학번·Wi-Fi 접속 정보가 있는 페이지와 기타 참고 자료 이미지는 공개하지 않았다. 원본 DOCX도 저장소에 포함하지 않는다. 시연 영상 링크는 보고서에서 가져왔다.

server/static/images/demo-layout.svg는 누락된 원 도면 대신 작성한 시연용 배치도다. 실제 공간의 치수나 배치를 나타내지 않는다.
