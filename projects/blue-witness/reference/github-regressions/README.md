# 원격 전용 회귀 테스트 보존

이번 source/server는 작성자의 로컬 개발본을 기준으로 갱신했습니다. 위 3개 파일은 이전 원격 통합본 `5148804`에만 있고 로컬 폴더에는 없던 테스트입니다. 삭제하거나 로컬 테스트인 것처럼 섞지 않고 비교 자료로 보존합니다.

로컬 소스와 원격 전체 테스트를 함께 실행한 74개 시험에서 실패 7개·오류 3개가 확인됐습니다. 삭제 중 일부 파일 이동 실패의 복원, DB 경로 호환 검증, 원격 구현에만 있는 함수·정책 등이 관련됩니다. 함수 계약 차이와 실제 후속 개선의 부재를 구분해 점검해야 합니다.

이 결과를 ‘로컬 코드에 모든 원격 회귀 수정이 포함됨’으로 해석하지 않습니다. 로컬 자체 시험 결과는 별도로 기록합니다. 이번 요청은 로컬 코드를 포트폴리오에 반영하는 것이므로 원격 버그 수정을 임의로 개발 폴더나 복제본에 재적용하지 않았습니다. 향후 최신 기능과 원격 개선을 합칠 때 이 시험도 함께 실행해야 합니다.
